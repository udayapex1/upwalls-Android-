## Overview

UpWalls is a production-ready wallpaper application built on the Expo ecosystem. It combines a curated visual discovery experience with a clean, scalable architecture — covering authenticated routes, optimized media delivery, and native-grade performance across iOS and Android from a single codebase.

---

## Features

- **Curated Discovery** — Trending feeds, category browsing, and algorithmically surfaced content designed to keep users engaged
- **Native Performance** — 60fps animations powered by Reanimated 4 and Native Gesture Handler
- **Secure Auth** — Token-based authentication with protected routes and secure local storage
- **Sharing & Deep Links** — Built-in share sheet integration and deep linking support
- **Zero Ads** — Clean, distraction-free experience with no advertisements
- **Cross-Platform** — Single codebase, fully native feel on both iOS and Android

---

## Tech Stack

| Layer | Technology | Purpose |
|-------|-----------|---------|
| Core Framework | React Native 0.81 | Native mobile runtime |
| Platform Engine | Expo SDK 54 | Managed workflow + OTA updates |
| Routing | Expo Router v6 | File-based navigation (Next.js-style) |
| State Management | Context API | Auth and global data flows |
| Networking | Axios | HTTP client for API communication |
| Animations | Reanimated 4 | High-performance gesture & transition animations |
| Visuals | Linear Gradient | Advanced visual effects and theming |

## Getting Started

### Prerequisites

- Node.js ≥ 18.x
- Expo CLI (`npm install -g expo-cli`)
- Android Studio or Xcode (for native builds)

### Setup

**1. Clone the repository**
```bash
git clone https://github.com/udayapex1/upwalls-Android-.git
cd upwalls-Android-
```

**2. Install dependencies**
```bash
npm install
```

**3. Start the development server**
```bash
npx expo start
```

**4. Run on device or emulator**
```bash
npx expo run:android   # Android
npx expo run:ios       # iOS
```
